Copilot V1 is a separate mode with private push-to-talk RU→EN TEXT using the existing Realtime translator, not a text Brain, command interpreter, TTS or Hint extension. This supersedes the earlier no-private-microphone research boundary. Implementation still requires approval of the exact routing design.

**Why:** The user rejected typing as the primary realtime input and rejected adding Terra/reasoning to simple translation. Owner dictates the actual desired message privately, then speaks its English translation to Guest themselves.

**How to apply:** Keep V1 independent from V2 conversation reasoning. Never equate private/generated/displayed content with speech Guest heard. A later Guest utterance must not by itself erase the Owner’s private intention; distinguish technical stale responses from semantic intent cancellation. No private content persistence beyond operational necessity without separate approval. Read the current user request before using older Copilot proposals.
