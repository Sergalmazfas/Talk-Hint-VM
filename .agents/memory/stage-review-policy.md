---
name: Правила v3 — порядок проверки по этапам
description: Решение владельца о работе внутри этапа, ZIP приёмки и неизменных ограничениях.
---

Работаем по этапам дорожной карты. Внутри этапа Replit делает сам: тестирует, коротко пишет, что сделал. ZIP на каждую правку не нужен.

Конец этапа — один ZIP приёмки на сверку Claude:
- что сделано и что нет;
- тесты;
- если этап касается команды — анкета каждого сотрудника отдельным JSON (обязанности, связи, промпт, запреты, статус) + общая карта связей.

Всегда до Publish, вне этапов: база, деньги, удаления, безопасность и ключи, массовые изменения модели.

Неизменно: галочку копирования Dev в production не ставить; данные модели правим только в production; самоприёмки нет.

**Why:** решение владельца о новом порядке проверки.

**How to apply:** этот порядок заменяет прежнее требование ZIP и сверки каждой правки. Указанные рискованные изменения остаются на сверке до Publish независимо от этапа.
