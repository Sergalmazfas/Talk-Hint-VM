The owner requested that ALL existing web functionality remain together in a
private administrator workspace: calling, cabinet, settings, diagnostics and
technical stands. Do not interpret this as moving only laboratories, deleting
the current phone UI, or reopening a public customer signup project.

**Why:** After cancelling the public-site/SMS implementation, the user explicitly
chose to keep the entire existing web workspace private while discussing the
future public product separately.

**How to apply:** Use the existing confirmed owner authorization, never a spoken
name, a new Google login or a provisioning account. Old direct addresses and
technical HTTP/WebSocket actions need server enforcement. Keep the root neutral.
Native iOS APIs/documents, Google callbacks, Twilio and ChatGPT OAuth/MCP are
separate compatibility boundaries; do not blanket-gate them as admin-only.
