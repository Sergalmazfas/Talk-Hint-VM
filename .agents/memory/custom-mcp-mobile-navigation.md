---
name: Прямая форма добавления custom MCP
description: Не отправлять владельца искать свой сервер в общем каталоге Replit.
---

Для добавления своего MCP использовать документированный переход
`https://replit.com/integrations?mcp=<base64 JSON>` с полями
`displayName` и `baseUrl`; JSON содержит только публичные параметры,
не секреты. Источник: https://docs.replit.com/build/connect-via-mcp.md.

**Why:** обычные ссылки на integrations/account неоднократно открывали
в мобильном интерфейсе каталог без нужной формы. Поиск собственного
несохранённого сервера в каталоге не решает подключение.

**How to apply:** сначала проверить актуальную документацию, сформировать
ссылку на форму и дать владельцу нажимаемую кнопку. Это не подтверждает
завершение OAuth; соединение отдельно проверять после авторизации.
