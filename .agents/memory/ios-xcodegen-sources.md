---
name: iOS XcodeGen source globbing
description: New Swift files under ios/TalkHint are auto-included; no pbxproj edits needed.
---

The iOS app is generated by **XcodeGen** from `ios/project.yml`. The TalkHint target
uses `sources: - path: TalkHint`, which globs the entire folder.

**Rule:** Adding a new `.swift` file anywhere under `ios/TalkHint/` is automatically
picked up on the next `xcodegen generate` — you do NOT need to edit a `.pbxproj`
(there isn't a committed one) or list the file anywhere.

**Why:** An earlier feature put a secondary view controller *inline* in an existing
file specifically to "avoid pbxproj changes." That caution was unnecessary here —
standalone files are fine and cleaner.

**How to apply:** Prefer a dedicated file per view controller. Just drop it under
`ios/TalkHint/UI/` (or the right subfolder). Can't compile/verify Swift on the Linux
container, so keep new VCs consistent with existing patterns (UITableViewController
list + async APIClient calls) and rely on review.
