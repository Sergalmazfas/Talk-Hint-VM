Нина Кадрова — P.ORG, существующий ID не менять; подчиняется владельцу,
статус «описана, не подключена». Сначала отработать процесс вручную,
подключение агентом — потом, не в рамках описания анкеты.

**Why:** прямое решение владельца: сначала процесс, потом автоматизация.

**How to apply:** анкету брать из предоставленного владельцем JSON v2;
не восстанавливать недостающие поля по догадке. Книжки знаний Замира,
Фомы, Кати и Тихона заполнять только подтверждёнными фактами с датой
и источником. Действующие промпты разложить на личность / знания / задачи
без изменения смысла, показать diff; это не разрешение переключать
рабочих агентов. Отложенные предложения R1–R5 прохода rev904 оформить
как proposed, не включать. Записи — через production MCP; один ZIP
анкет, знаний, слоёв и предложений в конце на сверку Claude.
