# Следующий этап: живые модели для подсказок

Решение владельца: отдельная новая серия с общим лимитом **$15**.
Это не пополнение и не сброс старой серии полигона.
Порядок: сначала Publish пакета English-first, разрешение владельца и пробный
звонок; затем этот стенд. Пока ни один платный запрос новой серии не выполнен.

## Изоляция и протокол

- Отдельные runner, идентификатор серии и долговечный ledger, без импорта в
  рабочий Hint. Без звонков, TTS пользователю, Кати, изменения её настроек.
- Gemini Live и GPT Realtime слушают оригинальное аудио Guest в реальном
  времени 1x. Короткая инструкция: роль суфлёра, сохранённая цель, только
  известные факты, одна краткая английская реплика для владельца.
- Ответ — простой текст, **не JSON**. Не подменять текстовый вывод транскрипцией
  сгенерированной речи и не подключать запасную модель незаметно.
- Каталог моделей и протокол сверяются по актуальной документации и реальному
  ответу API. Неподдерживаемый TEXT-режим Gemini — отдельный результат
  «не поддерживается», а не успех аудио-модели.
- Конец фразы определяет сам провайдер. У GPT — автоматический turn detection
  с автоответом; у Gemini — automatic activity detection. Никаких управляющих
  `activityEnd`, `input_audio_buffer.commit`, `response.create` по сигналу Flux/VAD.
- VAD по исходному звуку — исключительно независимая точка отсчёта, не триггер.
  Реплики Owner — отдельно маркированный контекст, не источник ответа Guest.
- Сначала один короткий контрактный контроль, затем самая короткая чистая
  запись и фиксированная малая панель. Синтетический контроль не доказывает
  прохождение многорепликового звонка.

## Измерение

- От физического конца речи Guest до первого полного английского слова.
- Отдельно: полная реплика, авто-EOT, прерывания, лишние ответы на Owner,
  наложения, пропуски, HTTP status/request-id, реальный model_id.
- Тот же независимый судья и шкала качества, что в предыдущей серии.
  Нулевые ответы остаются в оценке покрытия. Неоднозначность бракует отдельную
  реплику, звонок — только при доле >30%; ошибки API и часов — отдельно.
- Сравнение по тем же записям и физическим VAD-концам. Цель не придумывается.

## Деньги и приёмка

- До подключения — официальный тариф и запас на полную сессию, включая
  входное аудио, все разновидности кэша и выход. Лимит $15 общий для двух
  провайдеров, контроли и диагностика включены.
- Резерв долговечен до запроса; unknown целиком удерживается и не повторяется.
  Перезапуск/новый день бюджет не сбрасывает.
- Итог: скорость p50/p95, качество, покрытие, расходы/резервы, отказы и
  рекомендации. Ни один результат сам по себе не включает новый режим в продукт.
