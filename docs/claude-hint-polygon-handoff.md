# Новый изолированный полигон Hint — этап А

## Границы

Решение владельца: отдельный полигон рядом со старым, старый стенд и рабочий
Hint не менять. Корпус — существующие 36 записей владельца с автоматическим
поканальным VAD. Общая серия до $15, не в сутки. Новых звонков нет.
Рабочие промпты, модели сотрудников, Катя, звонки и Publish не затрагиваются.

Новый код — `server/hintPolygon/`, оператор — `scripts/hint-polygon.ts`.
Живой сервер НЕ импортирует этот код. Старый `server/benchmark/` не изменён.
Импортируются только чистые общие LIVE-builders промпта/запроса/нормализации.
Новых зависимостей, таблиц БД и маршрутов авторизации нет.

## Что работает

- Один замороженный корпус/хэш из всех 36 записей; оригинальные WAV проверяются
  SHA256 перед платными запросами, роли каналов сверяются с VAD.
- Воспроизведение двух каналов одновременно, 20 мс кадры, строго 1x.
  Абсолютный монотонный график, дрейф >300 мс делает прогон недействительным.
- Отсчёт от непаддированного VAD-конца речи внутри **аудиоокна** Flux.
  Не по номеру реплики и не по времени получения текста.
- Flux v2, `flux-general-en`, EOT 0.7 / 3000 мс; строки/числа времён Flux
  разбираются явно. Дренаж реальной тишиной 8 с; непокрытый хвост — ошибка.
- Terra, полный общий LIVE-промпт, 250 токенов, reasoning none, без temperature.
  Запросы отправляются сразу по EOT, не через скрытую последовательную очередь.
- В nonstream-профиле первое доступное английское слово, вся подсказка
  и перевод измеряются ПОСЛЕ разбора ответа. Это не первый байт JSON
  и не время рендера на настоящем iPhone.
- Независимый слепой судья `gpt-4.1-mini`: grounding, relevance,
  speakability, translation, 0–5. Только предшествующая история, не будущий
  ответ владельца. Неполный/неверный ответ судьи не заменяется успехом.
- Общая таблица CSV содержит рецепт, корпус, p50/p95, качество, цену,
  недействительные попытки. Их скорость/качество исключаются, расходы остаются.
- Промпт — отдельный реестр: текст шаблона, версия, длина, hash и история
  регистрации; динамические systemHash/длины пишутся по каждой реплике.
  Внедрения в рабочий Hint нет.
- Рецепт читается из JSON `--recipe=...`; схема strict, один фактор за раз,
  судья фиксирован. Нет молчаливой подмены модели/адаптера.

## Деньги и безопасность

Один постоянный `series-ledger.json` для ВСЕХ trial/диагностик, $15.
Атомарный reserve + fsync до запроса, единичная межпроцессная lease.
После исхода — usage/HTTP/request-id; unknown держит полную сумму резерва.
Нет суточного сброса, удаления расходов при новой версии или смене trial.
Повтор того же ID запрещён. Unknown-пayload запрещён даже под новым ID.
Отдельный действительно новый запрос возможен только в оставшемся бюджете.
Stale lease не снимается автоматически.

Цена — оценка по официальным ставкам и provider usage, НЕ invoice:
- Terra $2/$12, cache $0.20 за 1M:
  https://developers.openai.com/api/docs/models/gpt-5.6-terra
- Судья $0.40/$1.60, cache $0.10:
  https://developers.openai.com/api/docs/models/gpt-4.1-mini
- Flux English $0.0077/мин/канал, bill by seconds:
  https://deepgram.com/pricing

Ключи только из существующих Secrets в памяти процесса. В ZIP не включать
private-manifest/goals, аудио, транскрипты, окружение и записи разговоров.
В журнале API сохраняется очищенный текст ошибки/параметр, HTTP и request-id.

## Контрольный сбой судьи и исправление

Первая попытка: три подсказки Terra получены, затем судья HTTP400
invalid_request_error. Прогон INVALID, не используется в ранжировании.
Полный текст именно этого раннего ответа не сохранён — точную цитату не
выдумывать. Запрос остался unknown, полный резерв удержан.

Новый отдельный минимальный probe БЕЗ данных звонка подтвердил доступность
gpt-4.1-mini: HTTP200. В исходном запросе json_object не было явного слова
JSON в инструкциях. Это нарушает документированное требование JSON mode.
Исправлено только указание формата судьи; добавлен preflight, который
отклоняет такую ошибку ДО reserve/fetch. Старый unknown не повторялся
и не превращён в бесплатный. Исправленный baseline — отдельный trial,
история исходной попытки сохраняется.

## Что НЕ готово / не доказано

- После исправления JSON-инструкции второй контрольный прогон прерван из-за
  слишком строгой трактовки пустой подсказки. Лабораторный parser исправлен:
  пустая подсказка, которую LIVE нормализует в null, — отказ, а не обрыв.
- Третья попытка на ДРУГОЙ записи остановлена guard `STT_TAIL_NOT_COVERED`;
  одна граница речи сопоставлена, другая неоднозначна. Это НЕ доказательство
  потери аудио: возможны несовместимое окно, VAD-ошибка или отсутствие финала.
  Детальный журнал окон для ранних попыток не был сохранён; его добавили
  для следующих запусков. Ранее не сохранённые поля не выдумывались.
- Исправлен избыточный запрет на начало VAD-сегмента до начала rolling-window:
  если конец сегмента внутри окна, такое начало само по себе не неоднозначно.
  Live-проверка этого последнего изменения НЕ проводилась.
- Платные проверки после третьего STOP остановлены. Полный корпус не запущен.
  Ранние attempts/unknown сохранены, источник/окно требуют независимой сверки.
- В ранних trials сохранены code hash, но не полный снимок незакоммиченных
  исходников на каждый момент. Их побитовая воспроизводимость не доказана.
  Для будущих trials добавлен fsync-снимок исходников ДО первого запроса.
- Судья теперь видит также все отказы от подсказки, чтобы пропущенные вопросы
  не завышали качество. В таблице отдельно final/hint/abstention counts.

- B: GPT Realtime → Gemini Live; C: hint first; D: precompute;
  E: classifier/card; F: speculative — каталог есть, адаптеры
  **не реализованы**. Называть эти рецепты рабочими нельзя.
- Streaming, сокращённый промпт, раздельный перевод и другие STT-модели
  не реализованы. Конфиг не заменяет отсутствующий адаптер.
- Кэш OpenAI auto: нет выдуманного переключателя «off»;
  nonce-подмена промпта не выдаётся за честный однофакторный опыт.
- У 21 записи отсутствует сохранённая цель. Цель не придумана.
  Карточки/стратегия исторического live-контекста не восстановлены.
- Совпадение с полной живой цепочкой и экраном iPhone не доказано.
  Даже p50 в диапазоне 2–5 с само по себе не доказывает parity.
- B–F заблокированы до независимого подтверждения базовой линии.
  Самоприёмки базовой линии нет.
- Автопланировщик еженедельных идей Паши не добавлялся.

## Проверка

`npx vitest run server/hintPolygon --maxWorkers=1`

`npx tsc --noEmit`

В ZIP — фактический JSON тестов, только последняя валидная сводка.
Полный тестовый набор всего приложения новым полигоном не объявляется пройденным.

Проверить специально: резерв до сети; unknown не повторяется/не обнуляется;
остаток общий для trial; 1x и нулевой скрытый ускоритель; VAD/audio/channel
hash; пустые/битые/обрезанные результаты не ускоряют итог; judge truly distinct;
JSON-mode preflight; неизменность старого стенда и live-кода.

## Запуск оператором, не владельцем в UI

Readiness: `npx tsx scripts/hint-polygon.ts --trial=baseline-json-fix`

Canary: `npx tsx scripts/hint-polygon.ts --execute --trial=baseline-json-fix --limit=1`

Остаток: `--limit=36`, ТОЛЬКО после корректного завершения canary и сверки
хэша кода trial. Сейчас **все live-trial остановлены**, готового полного
baseline нет; команды выше не являются разрешением повторить unknown.
Уже обработанные записи trial не повторяются. При ошибке — STOP,
сохраняется INVALID и весь расход. Нельзя стирать lease/rows/ledger для продолжения.

Другой trial — НЕ повтор неизвестного запроса и НЕ новый бюджет:
старый журнал остаётся, хэш неизвестного запроса запрещает повтор независимо
от trial/ID. Новая попытка допустима только как явно обоснованный новый опыт.

Полный корпус требует примерно 96 мин 1x + дренаж/оценка.
Не обещать готовую таблицу всех 36 до фактического завершения.
