Это продолжение прежней ручной передачи в Xcode, не запуск GitHub Actions,
не новая разработка приложения и не разрешение на публикацию.

- Не TalkHint-Clean, не Expo-клиент.
- Новая ветка: **xcode-hint-dtmf-2026-10-30**.

  `d7ba7ce6449d93f039ebb296afc90eadae0968c2`.

  в отчёт и проверить, что отличия от коммита кода — только этот документ.

Код перенесён как отдельная native-правка на прежнюю Mac-базу:
11 путей внутри `ios/`. Существующий асинхронный тест

## Сначала сохранить чужую работу

1. Проверить `git status --short`, текущую ветку и HEAD.
2. Проверить владельца/репозиторий remote, не выводя credentials.
3. При незакоммиченной работе, своих коммитах или другом репозитории —
   остановиться и сообщить. Не делать stash, reset, clean, force или rebase.
4. В чистом checkout получить новую ветку:

```bash
git fetch --no-tags origin \
  refs/heads/xcode-hint-dtmf-2026-10-30:refs/remotes/origin/xcode-hint-dtmf-2026-10-30
git switch --create xcode-hint-dtmf-2026-10-30 \
  --track origin/xcode-hint-dtmf-2026-10-30
git rev-parse HEAD
git merge-base --is-ancestor a1278740f33ccc35e1bc5a270e9c6264968caf3c HEAD
git diff --exit-code a1278740f33ccc35e1bc5a270e9c6264968caf3c HEAD -- \
  . ':(exclude)docs/claude-mac-hint-dtmf-handoff.md'
```

Если локальная ветка уже существует, не пересоздавать и не перезаписывать:
сначала проверить её историю и совпадение с удалённой. Последние две проверки
должны завершиться с кодом 0 до запуска сборки.

## Что проверяем

- Только исходящий обычный Hint-звонок: отдельная кнопка клавиатуры.
- Все 12 клавиш: `0–9`, `*`, `#`.
- Отправка через существующий Twilio `Call.sendDigits` только для подключённого
  Hint-вызова с тем же UUID.
- Mute, End и выбор аудиовыхода сохранены.
- Нет очереди цифр, автоматического повтора после разрыва или повторного набора.
- Законченный звонок закрывает и открытый лист клавиатуры.
- Закрытие клавиатуры само по себе не завершает звонок.
- Входящие Hint-конференции, Translator, Copilot и Катя не изменяются.
- Локализации en/ru/es/kk/uk имеют одинаковые ключи и параметры.

Успешный вызов SDK означает отправку команды, а не доказательство принятия
цифры внешним IVR. В этой передаче нет реального телефонного теста.

## Сборка и XCTest — на Mac

Использовать прежние XcodeGen и native gate, не GitHub Actions.
В согласованной установке Xcode:

```bash
DEVELOPER_DIR=/Applications/Xcode_16.4.app/Contents/Developer \
  bash ios/scripts/validate-native.sh
```

Если Xcode установлен по другому пути, указать действующий путь и записать
версии Xcode/XcodeGen, SDK и симулятора в отчёт. Отсутствие инструмента/runtime —
блокер, не повод пропустить проверки.

Скрипт регенерирует проект, компилирует приложение и весь тестовый target,
проверяет подпись/entitlements изолированного симулятора, запускает XCTest
и проверяет xcresult. Не фильтровать только новые тесты.

Все пять `HintDtmfTests` обязательны:

1. `testAllTwelveKeysDispatchExactlyOnce`
2. `testInvalidAndDisconnectedDigitsNeverDispatch`
3. `testReconnectDoesNotReplayEarlierKeyPresses`
4. `testKeypadButtonsDispatchAndCompactScreenCanScroll`
5. `testFailedDispatchShowsErrorWithoutDisplayingUnsentDigits`

Дополнительно проверить компактный экран: клавиши прокручиваются, кнопка
закрытия доступна. Для проверки UIKit использовать изолированную фикстуру
с подставной отправкой цифр, без настоящего Twilio-звонка. Скриншот такой
фикстуры явно подписать: он не доказывает доставку DTMF внешнему меню.
Если полную связку экрана нельзя проверить без звонка — отметить ограничение,
не начинать звонок самостоятельно.

- Версии Xcode/XcodeGen/SDK/симулятора.
