# Emma Tutor v4 — Final Design Freeze Report

**Статус:** Compact mode — единственный интерфейс Emma Tutor v1. Fullscreen avatar mode полностью удалён из дизайн-пакета (фрейм с холста убран, кнопка Expand удалена с avatar card). **Production code НЕ менялся.**

## 1. Финальная геометрия avatar card
- Высота **260px**, радиус **28px**, на всю ширину контента (390 − 2×20 отступы = 350px).
- Тень: `0 12px 32px rgba(72,55,44,.13)` (тёплая).
- Нижний градиент-оверлей: black 25% → transparent (читаемость контролов).
- Оверлей-контролы (низ-право): только **Volume2 (mute)** — 36px круг, `bg-black/20` + blur, белая иконка 16px. Expand удалён.
- Индикатор речи (только в состоянии Speaking): пилюля white/70 + blur, 4 фиолетовые эквалайзер-полоски.

## 2. Framing Emma (утверждён вариант B — half-body)
- Голова–пояс, лицо — фокус верхней трети карточки; `object-cover`, focal point `center 24%`.
- Emma занимает ~75% карточки.
- **Разговорная поза:** руки свободны и естественны (перед собой/по бокам), БЕЗ ручки, карандаша, блокнота, бумаги, writing pose — изображение перегенерировано с этими ограничениями.

## 3. Background / Blur
- Уютный тёплый кабинет (книжные полки, растения, мягкий свет из окна), стилизованный 3D.
- Усиленный depth-of-field: интерьер — атмосферный фон, не конкурирует с лицом.

## 4. Chat
- Пузыри: радиус 20 (угол-якорь 6), padding 16×12, текст 14px lh 1.38, max-width 86%.
- Emma: #efedf0 / #39343e; пользователь: #7c3aed / white + фиолетовая тень; pending (запись): violet 55% + italic.
- Перевод — внутри пузыря Emma под разделителем 1px #d9d5db, 12px #77717d.
- Action row под пузырями Emma: Повторить (Volume2) + Перевод (Languages) основные, Копировать (Copy) приглушённый 55%.

## 5. Controls
- «Что сказать?» — пилюля #f5efff / #7131d6 с Lightbulb.
- Микрофон **70px**, #7c3aed, белая иконка 27px, glow `0 9px 24px rgba(124,58,237,.3)`.
- Второстепенные: клавиатура и скрепка — 48px круги #f0edf2.
- Статус-лейбл: 9px uppercase #aaa5af справа над микрофоном.

## 6. Icons
- Единая система **lucide** (stroke): X, Settings, Volume2, Languages, Copy, Lightbulb, Keyboard, Mic, Paperclip. Expand исключён. Эмодзи-иконок нет (эмодзи допустимы только внутри текста сообщений).

## 7. Animation states
- Микрофон: READY (violet) → RECORDING (#e64d5a + 2 пульс-кольца) → PROCESSING/disabled (#d8d5dc, без тени).
- Thinking: 3 анимированные фиолетовые точки в пузыре Emma.
- Speaking: эквалайзер на avatar card + стриминг текста в пузыре.
- **3D Emma (поведение, к реализации):** natural idle movement, моргание, малые движения головы, мимика, lip-sync, редкие естественные жесты рук/тела; приветственный взмах допустим один раз в начале сессии. Жесты редкие — не постоянная жестикуляция.

## 8. Что потребуется изменить в production implementation
1. `tutorAvatarPage.ts`: перекадровка камеры TalkingHead под вариант B (ближе, лицо в верхней трети) + фон-сцена в карточке (изображение окружения с blur) вместо плоского #dfe3ee.
2. Удалить кнопку/логику Fullscreen (Expand) и связанный код режима из страницы.
3. Заменить все эмодзи-глифы на SVG-иконки (lucide-набор выше), включая корректную иконку перевода.
4. Перестилизация: высота карточки 260px, радиусы/тени/типографика/цвета по разделам 1–5, новая иерархия нижних контролов (70px микрофон).
5. Анимации состояний: пульс-кольца записи, thinking-точки, speaking-эквалайзер.
6. Idle/gesture-поведение 3D-аватара (TalkingHead moods/gestures), приветственный wave при старте.
7. Локализация: без смешения RU/EN в хроме; исправить русскую строку `translateFailed` в EN-словаре.
8. Ничего сверх утверждённого: keyboard/attachments остаются как есть (плейсхолдеры), новых UX-фич нет.

**Канвас:** финальные фреймы — ряд y≈2160: Praktika-референс, 01 Ready, 02 Dialog, 03 Translate, 04 Recording, 05 Thinking, 06 Speaking, 07 Long + утверждённое кадрирование (08B). Fullscreen-фрейм и варианты кадрирования A/C удалены.
