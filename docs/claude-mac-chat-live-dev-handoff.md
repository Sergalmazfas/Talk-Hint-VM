# Claude на Mac: настоящий Chat в отдельной Dev-сборке

## Разрешение и границы

Владелец принял внешний вид и разрешил перенести исправления Claude в Dev,
проверить настоящий чат с реальным подключением. Дизайн не переделывать.
Это НЕ разрешение на Publish, Archive, TestFlight, платные звонки, репетиции,
Orb, подключение меню или изменение основной навигации.

Репозиторий: https://github.com/Sergalmazfas/Talk-Hint-VM
Ветка доставки: `xcode-chat-live-dev-2026-11-07`.
База доставки: `064e76e9718cb5444cdbeb8d37518b7de080c751`.
Точный новый HEAD получить через `git ls-remote` и сверить после fetch.

Исходные Mac-исправления получены из ZIP владельца, база `064e76e`,
код `18c564f`, отчёт `6d4ffb4`. Патчи прочитаны и перенесены без изменения
логики; автор исходных исправлений — Claude Code на Mac владельца.
Отдельные Mac-коммиты не выдаются за предков этой ветки: это аддитивный перенос.

## Что изменено

1. Исправления Claude: общий предок до активации bubble constraints,
   Auto Layout для прокрутки, сохранение черновика при первой загрузке,
   ожидание событий UIKit в тестах вместо фиксированных пауз.
2. Схема `TalkHintChatLiveDev`, конфигурация `ChatLiveDev`,
   флаг `TALKHINT_CHAT_LIVE_DEV`.
3. Отдельный bundle ID `app.talkhint.chatdev` и продукт `TalkHintChatDev`.
   Обычная установленная TalkHint не заменяется; её Keychain/UserDefaults
   не используются этой отдельной установкой.
4. Обычный экран входа → настоящий полноэкранный Chat с одобренным appearance.
   Стрелка назад в этой изолированной схеме возвращает на экран входа,
   не меняя основную навигацию. Черновики и история остаются сохранены.
5. Реальный URLSession, реальная авторизация, owner/origin-scoped черновики,
   реальные API. Нет фикстур, заглушек сообщений или обхода авторизации.
6. Нет инициализации push/телефонии при старте этой схемы. Диктовка сохраняет
   штатную проверку audio session; не инициировать звонки.
7. AppConfig требует явный HTTPS `.replit.dev` origin. При неправильном URL
   останавливается с объяснением, НЕ переключается на production.

Сервер чата УЖЕ существует в Replit: `server/chat/*`, регистрация в
`server/routes.ts`. Не писать новый сервер и не пытаться переносить весь
Replit checkout в Mac-репозиторий. Эта ветка передаёт только нативную дельту.

## Получение — без потери Mac-исправлений

Сначала показать `git status`, ветку, HEAD и свободное место. Старую
локальную ветку с `6d4ffb4`, её патчи и отчёт сохранить.
Fetch только штатного remote этого репозитория. На полученном remote HEAD
создать НОВУЮ локальную ветку в чистом выделенном worktree. При незакоммиченных
изменениях STOP: никакого stash/reset/rebase/force/merge.
Не накладывать заново Mac-патчи: они уже перенесены.

Проверить неизменность принятых Mac-регрессий, в том числе:

При нехватке места, подписи или профиля — STOP с причиной.

## Проверки перед показом

Сверить реальный Xcode, SDK/runtime, XcodeGen. Последнее подтверждённое:
Xcode 26.5 (17F42), `/Applications/Xcode.app`, XcodeGen 2.45.4,
iOS Simulator 26.5. Не переименовывать Xcode, не создавать подменяющие symlink.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  bash ios/scripts/validate-native.sh
```

Полный TalkHintTests без фильтрации и обязательный `verify-xcresult.py`.
Поимённый список унаследованных обязательных тестов:
`docs/chat-1a/MAC_REQUIRED_TESTS.md`. Все 33 Chat-теста (ChatAPITests,
ChatApprovedScreenTests, ChatDictationTests, ChatNavigationTests,
ChatOutboxTests) и прежние регрессии обязательны.
Прошлый результат 259/259 относится к старому Mac HEAD, не к новой доставке.
Не ослаблять assertions/тайм-ауты и не повторять неизменный прогон «до зелёного».
Отдельно сообщить о `Unbalanced calls to begin/end appearance transitions`,
если предупреждение повторяется; оно было даже в последнем успешном логе.

После gate:

```sh
cd ios
xcodegen generate --spec project.yml
open TalkHint.xcodeproj
```

Выбрать **TalkHintChatLiveDev**, arm64 iPhone Simulator, Run.
Не путать с офлайн **TalkHintChatPreview** или рабочей схемой **TalkHint**.
До запуска проверить resolved build settings: bundle ID именно
`app.talkhint.chatdev`, продукт `TalkHintChatDev`, флаг LIVE_DEV присутствует.
Отдельная сборка LIVE_DEV обязательна: native gate не компилирует эту ветку.

В Run → Environment уже задан Dev:
https://e62acc35-f5e5-43be-91ea-c3ad7b36be85-00-3l7jbsd7n4zci.janeway.replit.dev

Сервер Replit должен работать. Никаких production URL, токенов в схеме,
паролей в отчёте/чатах и отключения auth. Владелец сам вводит email/пароль
для Dev-аккаунта. Google-вход скрыт только в LIVE_DEV: старый OAuth callback
`talkhint://` принадлежит рабочему приложению и не должен перехватываться Dev.
Если аккаунта/пароля нет — STOP в этой части, без обхода
авторизации и создания админ-доступа.

## Что проверить с реальным API

- Вход, загрузка истории без фикстур.
- Черновик → назад → вход → восстановление.
- Прикрепление маленького `.txt`, повторное открытие; чужие файлы недоступны.
- Выход/перезапуск, история и незавершённый ответ; плохая сеть и повтор без дублей.
- AI-отправка и STT оплачиваются отдельно: не запускать самостоятельно без
  явного разрешения владельца на эти проверки. Обычный вход/чтение истории
  не является платным запросом к модели. Разрешение Replit на один запрос
  до $0.50 уже использовано: ответ `green-42`, 166 input / 7 output tokens,
  status complete. Это НЕ разрешение на дополнительные запросы с Mac.
- Для разрешённой владельцем ручной диктовки: настоящий meter, отмена,
  остановка, редактируемый текст; никакой автоматической отправки.
- Orb/«…» пока не работают по утверждённому объёму; Camera/Photos не выдавать
  за реализованные. Не расширять их.

На Replit уже проверены настоящий HTTPS Dev API с обычным Bearer auth,
создание/чтение в PostgreSQL, идемпотентность создания, изоляция двух
синтетических пользователей, upload/download реального App Storage.
Тестовые аккаунты и файл удалены. 209 серверных тестов и 36 source checks
прошли; они не заменяют запуск iOS.
