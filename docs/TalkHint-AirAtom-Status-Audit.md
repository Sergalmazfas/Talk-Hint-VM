# TalkHint + AirAtom — отчёт о состоянии (Status Audit)

> **Рамка отчёта:** анализ охватывает **только проект TalkHint**. Сторона AirAtom CRM
> (приём вебхука, анализ Claude, лиды, проекты, задачи, заметки, Apollo, email) живёт в
> **отдельном проекте**, недоступном в этом репозитории. Пункты «на стороне CRM» помечены
> как «вне TalkHint — проверить в проекте AirAtom».

**Обозначения:** 🟢 Работает · 🟡 Частично · 🔴 Не реализовано · ⚪️ Вне TalkHint (на стороне AirAtom)

## 1. Обработка звонков

| Пункт | Статус | Комментарий |
|---|---|---|
| Входящие звонки | 🟢 | `POST /twilio/voice`, определение владельца номера, hold-loop, push/SMS-уведомления |
| Исходящие звонки | 🟢 | из браузера/приложения (`client:user-…`), `<Dial>` + `<Stream>` |
| Живая транскрипция | 🟢 | Deepgram **Flux v2**, две дорожки, model-native turn detection |
| **Запись аудио звонка** | 🔴 | **TalkHint НЕ записывает аудио.** Есть только текстовая расшифровка. Поле `recordingUrl` существует, но всегда пустое |
| Генерация резюме звонка | 🟢 / ⚪️ | TalkHint делает короткое резюме для памяти контакта; **полный разбор (summary, ключевые точки, договорённости, sentiment) делает Claude на стороне AirAtom** |
| Разделение спикеров (Owner/Guest) | 🟢 | `server/speakerRoles.ts`, маппинг inbound/outbound → Owner/Guest |
| Сопоставление контакта | 🟢 | по номеру телефона через `contact_memory` (внутри TalkHint) |
| Сопоставление лида | ⚪️ | на стороне AirAtom |
| Сопоставление проекта | ⚪️ | на стороне AirAtom (auto-match) |
| Автосоздание задач | ⚪️ | на стороне AirAtom (Decisions/Tasks) |
| Автогенерация follow-up | ⚪️ | на стороне AirAtom |

**Главное:** допущение «звонки записываются» верно **только для текста**, не для аудио.

## 2. Интеграция с CRM

TalkHint отправляет в AirAtom после каждого звонка вебхук с полями:
`callId` (Twilio SID) · `transcript` (полный текст с метками спикеров) · `callerName` · `durationSecs`.
Есть **надёжная очередь повторов** (`airatoma_deliveries`, до 8 попыток с экспоненциальным backoff):
если первая попытка отваливается по таймауту, повтор уходит позже и фиксируется статусом 200.

| Пункт | Статус | Комментарий |
|---|---|---|
| Звонок ↔ Лид | ⚪️ | связывает AirAtom |
| Звонок ↔ Контакт | ⚪️ | AirAtom (по callId/номеру) |
| Звонок ↔ Проект | ⚪️ | AirAtom |
| Таймлайн/история | 🟡 | в TalkHint есть таблица `calls` + `/api/calls`; **показывает только iOS-приложение**, в веб-кабинете истории нет |
| Поиск по истории звонков | 🔴 | данные хранятся, но поиска/фильтра нет |
| Хранение резюме | 🟢 | короткое резюме в `contact_memory` |
| Хранение транскрипта | 🟢 | в `calls.transcript` |
| AI-заметки | 🟡 / ⚪️ | внутренние заметки контакта в TalkHint есть; CRM-заметки — на стороне AirAtom |

## 5. Режимы ассистента

Сейчас режимы в коде — **универсальный / массаж / диспетчер / тренировка** (это контекст, а не уровни A/B/C).
Трёх уровней как переключателей нет, но по функциям:

| Режим | Статус | Комментарий |
|---|---|---|
| **A. Только запись** (транскрипт+резюме, без подсказок) | 🟡 | транскрипт+резюме+отправка в CRM работают всегда, **но отключить подсказки/перевод нельзя** — нет тумблера |
| **B. Copilot** (подсказки, без перевода, быстро) | 🟡 | подсказки есть, но перевод всегда «вшит» в ответ — отдельного «без перевода» нет |
| **C. Full Assist** (подсказки+перевод+контекст CRM+память контакта) | 🟢 | поведение по умолчанию: `translateAndSuggest` отдаёт перевод, подсказку, перевод подсказки, sentiment + подмешивает userContext/память/карточки |

**Вывод:** C по факту готов, **A и B требуют добавить переключатель режимов** (вкл/выкл подсказок и перевода).

## 8. Топ-5 задач с наибольшим эффектом

1. **Запись аудио звонков (Twilio Recording) + ссылка в CRM.** Сейчас главный пробел: есть только текст.
   Запись даёт перепрослушивание, контроль качества и материал для будущего обучения AI.
   *(Надёжность + ценность CRM + сбор данных для AI).*
2. **История звонков в веб-кабинете + поиск.** Данные уже в БД, но в вебе их не видно (только iOS).
   Список + поиск по тексту/контакту/дате — быстрый, высокоокупаемый шаг. *(Ценность CRM + сбор данных).*
3. **Переключатель режимов A/B/C** (Только запись / Copilot / Full Assist) с реальными тумблерами
   подсказок и перевода. Закрывает явный запрос и снижает «шум» там, где подсказки не нужны. *(Скорость + UX).*
4. **Сквозная сверка доставки в CRM (dashboard статуса).** Очередь повторов есть, но оператору не видно
   «дошло/не дошло». Панель `airatoma_deliveries` (pending/delivered/failed) + бейдж в кабинете уберёт
   вопросы «ушло ли в CRM?». *(Надёжность).*
5. **Фундамент обучения на прошлых звонках:** размечать успешные разговоры (тег «успех» по достижению
   цели Goal Engine) и автонаполнять knowledge cards / шаблоны подсказок из них. Первый шаг к плейбукам
   и «подсказкам от лучших». *(Будущее AI-обучение).*
