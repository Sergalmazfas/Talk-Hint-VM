## Только после отдельного разрешения запуска (не часть текущего этапа)

Owner-only API `/api/admin/ai-crew/command` принимает `{revision,command}`.
Все три новые кнопки требуют «Вы уверены?», получают свежую revision и CSRF
из GET `/api/admin/ai-crew`, после записи перечитывают и проверяют результат.
При ошибке/неясном ответе POST не повторяется; до ручного обновления кнопки
заблокированы. Аварийный OFF не заблокирован и отменяет ещё не отправленный шаг.
JSON-редактор по-прежнему не разрешает enabled:true: включение — отдельной кнопкой.

- в поле USD по умолчанию **$1**; владелец выбирает сумму и нажимает
  **«Включить с лимитом»**, подтверждает точную сумму;
- **«Запустить пилот»**, подтверждает запуск. Кнопка доступна только при
  подготовленной задаче, включённом контроле и положительном лимите;
- проверить Пашу done/proposed → Фому done/proposed → verdict для владельца;
  задача analysis не закрывается автоматически;
- панель обновляет только GET каждые 5 секунд во время author/review;
- после Фомы сервер атомарно возвращает **OFF, лимит не меняет**. Панель показывает
  предложение Паши, вердикт и разбор Фомы, цену в USD и токены каждого.
- общий «Аварийно выключить всё» остаётся доступен. Неизвестный расход не считается
  нулевым, оставшийся резерв показан отдельно. Ошибка/обрыв не запускает повтор.
