## Что изменено

- Клавиатура скрывается тапом по переписке и кнопкой Done над клавиатурой.
  Тапы по карточкам, вложениям и кнопкам не перехватываются.
- В сообщениях хранится необязательная карточка плана: цель, чек-лист,
  подтверждённые факты, ожидаемые вопросы/ответы, неизвестное, разрешённое и
  запрещённое, язык звонка, телефон и voicemail.
- Перед сохранением/передачей — явная проверка именно этого плана.
- Hint: API сохраняет план для следующего подходящего звонка, сам не звонит.
- Катя: API возвращает временное подтверждение; открывается существующий
  `SecretaryTaskReviewViewController`. Только его отдельная кнопка Start
  может начать настоящий звонок. В этой проверке её НЕ нажимать.
- Читаемое представление отделено от канонической инструкции: подпись,
  recovery и запрос Start используют исходную полную инструкцию, не её
  отображаемую копию. Токен не хранится в чатах/outbox/UserDefaults.
- Старые сообщения без action и все пять локализаций поддержаны.

## Сервер

Новый endpoint: `POST /api/chat-v1/conversations/:id/messages/:messageId/confirm-plan`.
Он требует native-аутентификацию и `planHash`, не принимает userId/план/права
из тела. Старый план после коррекции в чате отклоняется.
В Dev добавлена nullable `chat_messages.action jsonb`; production меняется
только отдельным Publish владельца. Не пытаться применить DDL с Mac.
До этого Publish рабочий сервер не обязан поддерживать endpoint.

Не менять серверный адрес, bundle, URL-схемы, модель, голос и Retell.
Основной iPhone — обычная схема TalkHint с уже проверенными настройками;
не создавать третье приложение и не устанавливать AppDev вместо основного.
Не удалять установленное приложение: обновление с сохранением данных.

Сначала проверить версии и путь Xcode; последний известный — Xcode 26.5,
`/Applications/Xcode.app`, XcodeGen 2.45.4. Не переименовывать Xcode и не

## Ручные неплатные проверки

Использовать URLProtocol/mock API либо сохранённые fixtures, не OpenAI/STT:

1. Набрать черновик, открыть клавиатуру; закрыть тапом и Done; текст на месте.
2. Полистать историю на маленьком экране, вернуть клавиатуру; проверить
   диктовку с заглушенной расшифровкой, вложения и доступность кнопок.
3. Показать fixture полной карточки плана EN/RU/ES; исправленный бюджет и
   запреты видны целиком. Отмена alert не отправляет POST.
4. Hint: один POST; повтор/сетевая неоднозначность используют тот же message
   и hash. После успешного сохранения нет второго сохранения.
5. Secretary: карточка → подтверждение → существующий экран review без JSON.
   Убедиться, что HTTP-запрос Start вообще не отправлен. Start не нажимать.
6. Ошибка/устаревший план/закрытие чата/смена аккаунта во время запроса не
   открывают чужую карточку или экран. Перезапуск восстанавливает план, не
   подтверждает и не запускает его автоматически.
7. Назад из review возвращает в тот же Chat; выход из Chat — в прежнюю вкладку.
   Номеронабиратель и навигация остальных вкладок не меняются.

Никаких платных AI, STT, звонков/репетиций, production-записей, Publish,
Archive/TestFlight/App Store, смены Apple Team/сертификатов и работы с ключами.
Не чистить диски/симуляторы/кэши без отдельного разрешения. Если понадобится
платная ручная проверка — её отдельно делает владелец.
