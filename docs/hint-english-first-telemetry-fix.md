# Hint: сохранение телеметрии и гонка лаборатории

## Диагноз

Завершение телефонного звонка и финальное сохранение Hint — разные события.
Лаборатория могла прочитать завершённую строку до отложенного flush с окном ACK
1500 мс и сохранить окончательное уведомление `unknown`. Повторное чтение строки
впоследствии уже находило labHintSource, hintLatency и hintUsage, но готовое
уведомление автоматически не пересчитывалось.

В проверенном звонке на сборке 85c03ff журнал лаборатории начинает claim
14:49:55.510 UTC. Закрытие Hint-stream отмечено 14:49:54.298 UTC:
1500-мс окно ещё не истекло. Это согласуется с обнаруженной гонкой.

Сам по себе номер сборки не доказывает вариант Hint. У пользователя звонка
после звонка сохранены legacy/revision 0, а provider_used в журнале всех
найденных отправок — openai:gpt-5.6-terra, без суффикса english-first.
Этот звонок нельзя представлять проверкой ускорения новой ветки.

## Изменено

- Владелец потока Hint получает раннюю запись mode=hint и collecting при
  действующем owner-only разрешении лаборатории.
- Начальное сохранение сериализовано перед финальным: медленный ранний
  collecting не может затереть ready.
- Финальный ready и телеметрия сохраняются одним merge после окна ACK.
- Reconciliation не забирает collecting до завершения; через две минуты
  незавершённый снимок становится честным unavailable, не успешным разбором.
- Для неизвестного режима предусмотрена дополнительная пауза 10 секунд,
  чтобы преждевременный callback завершения не создал окончательный unknown.
- Каждый ход записывает responseMode; звонок — hintResponseMode
  (legacy / english-first / mixed). Наличие библиотеки не скрывается:
  старый source библиотеки остаётся отдельным полем.
- readyAt остаётся временем готовности полного английского; отдельно
  translationReadyAt и translationSentAt. Поздний перевод не считается
  второй подсказкой. Существующие ACK и hintUsage сохранены.
- В снимок лаборатории передаются эти этапы и usage. Детерминированный
  отчёт считает STT-final→английский и STT-final→перевод.
- Физический конец речи не измеряется. Новые поля не восстанавливаются
  задним числом из сегодняшнего положения переключателя.

analysis присутствует, qa_issues пуст. Логика доставки не менялась.

## Сохранённый звонок

Выполнен один явно запрошенный повторный разбор существующим ручным механизмом
лаборатории из Dev: независимая QA вернула «QA: расхождения не устранены».
Исходные production-звонок и уведомление не изменены. Новых звонков, аудио,
повтора отправки письма и изменения owner-флагов нет. Ручной результат не
доказывает восстановление автоматической лаборатории в production.

## Публикация и ограничения

Нет DDL, новых таблиц/колонок, изменений промптов, моделей, Кати или iOS.
Публикует владелец; Copy development database to production — выключено.
Новая серверная логика начнёт действовать только после Publish.
Переключатель Hint не изменялся: публикация не включает English-first.
Физический iPhone и автоматическая обработка нового production-звонка этим
пакетом не проверены.
