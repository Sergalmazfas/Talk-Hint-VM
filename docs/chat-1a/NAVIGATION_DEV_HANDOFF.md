# TalkHint Chat — согласованная навигация в Dev

## Реализовано в исходниках

1. Существующие пять входов и их tags 0–4 сохранены. В середине — вход Chat,
   не Copilot. Главный экран — прежний Hint/номеронабиратель, без новых плиток.
   Hint/Translator/Secretary/History сохраняют прежние контроллеры и иконки.
2. Chat перехватывается делегатом нижней панели и открывает отдельный
   `.fullScreen` navigation stack. Предыдущая вкладка остаётся выбранной
   за ним. Реальный Chat не является корневым экраном вкладки.
3. Слева сверху — стрелка выхода. Справа — отдельная кнопка меню.
   Внутри полноэкранного Chat нижних вкладок нет. Выход не уничтожает
   сохранённый экземпляр чата/навигационного стека.
4. Возврат не запускает повторную полную инициализацию composer. История
   остаётся в существующих API/БД, черновик/вложения — в прежнем owner/origin
   draft store. Позиция чтения сохраняется и восстанавливается с учётом
   доступной высоты. Состояние сообщений обновляется чтением; новые AI/STT
   запросы при возврате не запускаются.
5. Боковое меню выезжает слева, имеет затемнение и закрытие по нажатию вне
   панели. Содержимое прокручивается, элементы имеют минимальную высоту 44.
   Новый/недавние чаты действуют. Calendar, Tasks, Notebook, Contacts, Files,
   Mail, My card, Connections, Plan, Help, About — явно неактивные пункты с одной общей
   подписью, без повторения Later. Проектов нет.
6. Settings открывает **существующий** `SettingsViewController(api:)`.
   Проверены его зависимости: APIClient и SessionStore, без зависимости
   от HomeViewController/выбранной вкладки. Параметры, способы сохранения,
   имеющиеся подразделы и вход через шестерёнку Hint не менялись.
   Кнопка Settings закреплена внизу панели и не теряется за длинной историей.
   В стеке настроек видна обычная системная навигация; назад возвращает
   тот же Chat, скрывая системную панель, дублирующую его заголовок.
7. При внешнем выборе вкладки (например, существующим Secretary/APNs
   маршрутизатором) чат уступает этому экрану. Если поверх чата открыт
   экран звонка, закрытие чата **не dismiss-ит** его; переход ожидает
   возвращения контейнера. Сам CallManager/уведомления не изменены.
8. Текущие диктовка, вложения, цвета сообщений, редактирование, отправка
   и отключённая кнопка будущего Voice Orb сохранены. Для клавиатуры
   остаётся существующий keyboardLayoutGuide. Уход со страницы отменяет
   диктовку без отправки и сохраняет черновик; открытие меню также
   завершает диктовку отменой, не платным распознаванием.
9. Новые подписи переведены на EN/ES/RU/KK/UK; выбор языка прежний,
   системный. Новых настроек языка не добавлялось.

## Файлы

- `ios/TalkHint/App/SceneDelegate.swift` — прежняя панель, новый вход Chat.
- `ios/TalkHint/Chat/ChatNavigation.swift` — отдельный retained-контейнер.
- `ios/TalkHint/Chat/ChatViewController.swift` — back/menu, scroll/resume,
  существующие Settings и прокручиваемое меню.
- Пять `Localizable.strings` — подписи back/menu/contacts/availability note.
- `ChatNavigationTests`, `CopilotFreezeNavigationTests`, source-contract tests,
  регистрация обязательных тестов в `verify-xcresult.py`.

Нативные тесты используют UIWindowScene, локальный fixture transport и
изолированный UserDefaults suite. Нет записи микрофона, STT, модели,
телефонного звонка или сетевого доступа к провайдерам.
Один сценарий проверяет имитацию экрана звонка, **не реальный PSTN/CallKit**.

## На Mac

Нужен текущий Dev-код диктовки из предыдущего пакета. Базовый SHA указан
в ZIP; не применять navigation patch повторно или к несвязанной версии.
Сохранить свои изменения до переноса.

Из корня существующего репозитория:

```sh
git status --short
bash ios/scripts/validate-native.sh
```

Harness регенерирует проект, собирает validation-схему, выполняет полный
XCTest и проверяет xcresult. В обязательные включены новые 7 сценариев
и 2 navigation/freezing-регрессии. Archive/TestFlight/Publish не запускать.

Ручная Dev-проверка: Hint/Translator/Secretary/History → Chat → назад;
меню → настройки → обратно; длинная переписка/черновик → выход/возврат;
маленький экран/клавиатура/диктовка; EN/ES/RU и тёмная тема.
Настоящее платное STT — только при отдельно разрешённой ручной проверке.
Живой звонок для автоматической приёмки не запускать.

## Изображения и ограничения

В ZIP четыре крупных **концепта**, отражающих новую навигацию. Это не
скриншоты запущенного UIKit и не доказательство размеров на iPhone.
Главный экран и настройки не перерисованы. Положение/вид системных
элементов и keyboard/микрофон надо сверить на настоящей Dev-сборке.

Production, Retell, настройки голосового движка и маршруты телефонии
не менялись. Деплой, платные звонки и репетиции не выполнялись.
Новая память, календарь, почта, внешние действия и Voice Orb не внедрялись.
