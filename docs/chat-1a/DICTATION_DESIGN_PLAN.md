## 2. Существующая реализация → пробел → предложение

Проверено чтением `ios/TalkHint/Chat/ChatViewController.swift`,
`toggleRecording`, `startRecording`, `stopRecording`, `restoreAudioSession`.

| Сейчас | Пробел | Предлагается после согласования |
|---|---|---|
| Микрофон нарисован `waveform`, при записи меняется на красный `stop.fill` | Нет компактной панели с волной/отменой | Микрофон в обычном вводе; во время записи та же область превращается в панель диктовки |
| AVAudioRecorder, AAC mono 16 kHz | Нет metering/updateMeters и визуализации уровня | Реальная волна из локального уровня аудио, без отправки в модель |
| Повторный тап останавливает запись и запускает существующий `prepareTranscribe` | Нет явных состояний запроса/распознавания и защиты от повторных тапов по состоянию | Одна state machine, recordingId, один активный запрос; отдельный recognitionAttemptId для явно запрошенного повтора |
| Результат записывается через `composer.text = transcript` | Заменяет ранее набранный текст; поздний ответ может попасть не в тот контекст | Зафиксировать чат/черновик/позицию вставки; не перезаписывать изменённый пользователем текст |
| Есть проверка текущего пользователя после ответа | Этого недостаточно при смене чата или новой диктовке того же пользователя | Проверять owner + conversation + recordingId + draft revision |
| Ошибки разрешения/распознавания показываются общим текстом | Нет отдельных действий для denied / network / no speech | Разные короткие сообщения и подходящие кнопки, без бесконечного автоматического повтора |
| При уходе с экрана используется discard | В ветке discard выход происходит до удаления временного файла | Планировать единый финализатор для отмены/ошибки/завершения и проверку очистки |
| Текст после распознавания не отправляется сам | Правильная безопасная основа | Сохранить явную проверку и отправку пользователем |
| Уже есть защита CallManager/AVAudioSession и восстановление категории | Нельзя повредить телефонное аудио | Сохранить защиты и проверить прерывания; не вводить новый телефонный движок |
| Запись ограничена существующими 60 секундами | Не предмет изменения этой задачи | Лимит не менять; он относится только к диктовке, не к звонкам |

## 3. Полный цикл

```text
Обычный ввод
  └─ микрофон → проверка разрешения/занятости аудио
       ├─ разрешено → Запись: × + волна + ■ + неактивная ↑
       ├─ ещё не решено → системный запрос → разрешено / отказ
       ├─ отказ → объяснение + Настройки
       └─ телефонное аудио занято → объяснение, запись не начинается

Запись
  ├─ × → отмена, исходный текст/вложения сохранены, STT не запускается
  ├─ ■ → запись остановлена → Распознавание
  └─ прерывание/уход → запись прекращена; нет автопродолжения/автоотправки

Распознавание
  ├─ отмена → результат больше не применяется
  ├─ текст готов → Редактируемый черновик
  ├─ речь не распознана → Повторить диктовку / Отмена
  └─ сеть/сервис недоступен → явный Повторить / Отмена

Редактируемый черновик
  ├─ правка → обычная клавиатура, тот же черновик
  ├─ новая диктовка → добавление к тексту; замена только явно
  └─ ↑ → существующая отправка с clientRequestId → Отправлено / ошибка отправки
```

**Стрелка во время записи:** предлагаем показывать её неактивной до готового
текста. Это осознанное предложение безопасности: квадрат завершает запись,
стрелка отправляет только проверяемый текст. На референсе стрелка видна,
но её действие по скриншоту неизвестно. Это решение требуется согласовать.

Отмена распознавания не означает, что уже отправленный внешнему сервису
запрос не стоил денег. Предложение — прекратить локальное ожидание и не
применять поздний результат; сетевую задачу отменять, где это возможно.

## 4. Поведение панели и соседних элементов

- Волна занимает место текста в компактной нижней капсуле. История остаётся
  видимой. Никаких полноэкранных микрофонов, шаров, озвучивания ответа.
- Волна показывает громкость/активность, **не** уверенность распознавания.
  Тишина — спокойные точки/малые столбцы, голос — изменяющиеся столбцы.
  Предлагается обновление уровня порядка 20 раз/сек с плавной анимацией;
  финальную частоту выбрать после нативной проверки батареи и плавности.
- GIF в пакете — синтетическая демонстрация движения. Он не использует
  микрофон и не доказывает реакцию реализованного iOS-интерфейса.
- При начале записи клавиатура уходит; панель остаётся над нижней навигацией.
  При правке текста клавиатура появляется; поле привязано к keyboardLayoutGuide.
  Скрытие вкладок при клавиатуре — предложение, а не проверенное текущее поведение.
- Плюс открывает доступное прикрепление **файла**. Camera/Photos/Plugins из
  ChatGPT не объявляются готовыми функциями TalkHint.
- Уже выбранное вложение остаётся в черновике. Во время записи плюс не
  запускает конкурирующий выбор файла. Смена чата/вкладки должна явно
  предупреждать о потере незавершённой диктовки, не о потере набранного текста.
- При переходе в фон/телефонном прерывании — остановка записи и отсутствие
  автоматического возобновления. Для данной версии предлагается отмена
  незавершённой диктовки с понятным сообщением; исходный черновик сохраняется.
- После возврата из системных Настроек микрофон не начинает запись сам.
- EN/ES/RU — язык приложения iOS, не отдельный язык интерфейса диктовки.
  Это не предложение менять язык действующего распознавания.
- Светлая и тёмная темы сохраняют геометрию и смысл кнопок. Dynamic Type,
  контраст, VoiceOver, Reduce Motion и hit targets проверяются на iOS.

## 5. Короткий безопасный план реализации — только после «да»

1. Зафиксировать утверждённые изображения, семантику стрелки и переходы.
2. Выделить UI-панель и состояние диктовки, переиспользовать AVAudioRecorder
   и текущий авторизованный серверный путь распознавания. Не менять модели,
   телефонные маршруты, аудиодвижок звонков и доступы.
3. Добавить локальный metering для волны. Скрытие/появление панели и
   клавиатуры проверить на Simulator/устройстве, не по статичной картинке.
4. Ввести отменяемую задачу и контекст записи; блокировать повторный stop,
   поздний результат и подмену текста другого черновика. Не сохранять raw
   audio как вложение и не добавлять новое постоянное хранилище аудио.
5. Сохранить clientRequestId существующей отправки. Никаких запросов AI
   от движения волны, автоматической отправки или автоматического retry.
6. Очистку временного файла и восстановление AVAudioSession выполнять
   одинаково во всех выходах; не выводить аудио и текст в диагностические логи.
7. Добавить локализованные строки/доступные названия кнопок и проверки.
   Реальные STT-пробы — только после отдельного разрешения, не в этом пакете.

## 6. Предлагаемые проверки после реализации

| Проверка | Ожидаемый результат |
|---|---|
| Быстрые повторные тапы / двойной stop | Не больше одной записи и одного STT-запроса на попытку, без явного повтора |
| Отмена до stop | 0 STT-запросов, 0 отправленных сообщений |
| Отмена/смена чата/пользователя во время STT | 0 применений устаревшего результата |
| До диктовки уже были текст и файл | 0 потерь исходного текста и вложений |
| Ошибка сети / пустая речь / отказ разрешения | Различимые состояния; 0 автоматических повторов |
| Результат готов, пользователь ничего не нажимает | 0 отправленных сообщений |
| Повторный тап ↑ при проблеме сети | 0 дублей по clientRequestId |
| Звонок/фон/выход/ошибка | Микрофон освобождён, временный файл очищен, нет автостарта |
| Светлая/тёмная, EN/ES/RU, крупный шрифт | Нет перекрытий панели/клавиатуры; названия кнопок доступны |

Сначала тесты со стабами и синтетическими уровнями аудио, затем визуальная
проверка на Mac/iPhone. В текущем задании эти проверки **не выполнялись**:
код не внедрялся, реальные запись/распознавание/отправка не запускались.

## 7. Границы пакета

Только дизайн и план микрофона. Voice Orb — отдельное следующее решение.
Нет реализации, production-изменений, Publish, звонков и платных тестов.
Изображения — концепты, не доказательство работы UIKit и системных анимаций.
