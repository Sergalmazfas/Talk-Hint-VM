# TalkHint Chat: подготовка рабочего сервера и iPhone

## Цель и состояние

Владелец выбрал всё приложение с Chat и подключение сразу к рабочему серверу.
Проверенный опубликованный адрес: **https://talkhint.app**, Reserved VM.
Серверная часть подготовлена к Publish владельцем. Новая iPhone-сборка ещё
не установлена: её сборку и проверки выполняет Claude на Mac.

Нативная дельта передана в GitHub:

- [Ветка передачи](https://github.com/Sergalmazfas/Talk-Hint-VM/tree/xcode-chat-iphone-ready-2026-11-09)
- [Коммит 160181a](https://github.com/Sergalmazfas/Talk-Hint-VM/commit/160181ad72885551833b7477b5380ed26a96b660)
- [Полное задание Claude](https://github.com/Sergalmazfas/Talk-Hint-VM/blob/xcode-chat-iphone-ready-2026-11-09/docs/claude-mac-chat-iphone-handoff.md)

Передача — только нового коммита поверх существующего Mac HEAD 85ec300.
Не заменять Mac-копию деревом Replit и не переносить прежние исправления повторно.

## Исправлено

- Google и password auth не объявляют успешный вход, пока Keychain не подтвердил
  запись и чтение токена. При отказе очищается привязка идентичности; токен
  не переезжает в UserDefaults.
- Ошибка безопасного хранения локализована EN/ES/RU/KK/UK.
- Потерянная сессия при открытии Chat больше не вызывает precondition crash.
- Обычная схема TalkHint тоже открывает подключённый утверждённый Chat вместо Copilot.
  Внутри чата нижней панели нет, прежние телефонные вкладки сохраняются.
- Dev-схемы получили явный build-bound Dev origin для запуска с иконки без Xcode.
  Не добавлен production fallback для Dev.
- Убрано actor-небезопасное создание Chat из аргумента по умолчанию; QuickLook
  cleanup переводится на MainActor, с привязкой к конкретному preview.
- Исправлена первая миграция чата: table-level UNIQUE для составного owner FK.
  Работающая Dev-база имела нужный индекс, но первоначальный Publish diff его
  не включал. Защита владельца и прежние индексы не удалены.

## Что не объявлено исправленным

Все 82 прежних compiler warnings и 13 `Unbalanced calls` нельзя считать
исправленными по исходникам. Два предупреждения чата адресованы текущей дельтой,
но исчезновение подтверждает только новый Xcode build.
Предупреждения телефонии/аудио требуют проверки причин на Mac, без массового
скрытия concurrency diagnostics. Точная процедура и границы — в задании Claude.

Прежние 261/0/0 — доказательство предыдущего Mac-снимка, не нового коммита.
Добавлены шесть XCTest SessionCredentials; здесь их невозможно запустить без Xcode.
Настоящие AI/STT на production и платные звонки автоматически не проверялись.
Голос Merritt, модели, Retell, планы и длительность живых звонков не менялись.

## Два отдельных действия

1. Владелец публикует сервер в Replit. Сохраняем текущую VM и команды запуска.
   Новая схема только добавляет таблицы, индексы и ограничение связи. Не выбирать
   overwrite data. Если фактический Publish предлагает удаление — остановиться.
   Внешний ключ с `ON DELETE no action` не является командой удаления данных.
2. Claude проходит gate и собирает **TalkHint / app.talkhint / talkhint** для
   физического iPhone, с рабочим backend https://talkhint.app. Не AppDev.
   Установка с тем же bundle обновляет основное приложение; удалять его и его
   данные нельзя. Проверить вход Google и запуск с иконки после отключения Xcode.

Publish сайта не устанавливает нативное приложение. Archive/TestFlight не разрешены
этой инструкцией. Первый настоящий AI-запрос и звонок проверяет владелец.
