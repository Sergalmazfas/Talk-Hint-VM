# TalkHint Chat 1A — диктовка в Dev

## Граница результата

Изменены исходники существующего iOS-клиента. Это **не опубликованная
и не собранная здесь iPhone-версия**. Production, серверные API, Retell,
звонки, голос, модели и их лимиты не изменялись. Автоматических платных
STT/AI-запросов, репетиций и звонков не было.

## Что реализовано

- Компактный ввод: `+`, текст, **микрофон диктовки**, стрелка при наличии
  текста/вложения и отдельная чёрная кнопка с аудиоволной.
- Кнопка будущего Voice Orb отключена и подписана как недоступная. У неё
  нет обработчика запуска. Контракт будущего перехода — текущий ownerId и
  conversationId; те же сообщения и память, не новая параллельная история.
  Полноэкранный режим, аудиозвонок, ElevenLabs и другие движки не реализованы.
- Во время записи поле заменяется панелью с отменой, стопом, временем и
  полосой, получающей `AVAudioRecorder.updateMeters()` / `averagePower`.
  Данные для полосы локальные, без сетевых запросов. Во время распознавания
  — явное ожидание с отменой. Стоп не отправляет сообщение.
- Используется прежний авторизованный `prepareTranscribe` /
  `/api/prepare/stt`. Диктовка не превращает PREP в хранилище переписки.
  Распознанное вставляется в исходное выделение UITextView; остальной текст
  сохраняется. После этого — редактирование и отдельный тап отправки.
- Поздние результаты проверяют owner, conversation, draftRevision и
  recognition attempt. Повторный stop/retry не создаёт параллельный запрос.
  Сетевой повтор только явным нажатием. Отмена отменяет клиентский Task;
  уже принятый провайдером запрос может всё равно быть оплачен.
- Отказ в разрешении открывает объяснение и кнопку системных настроек;
  возврат из настроек не начинает запись автоматически.
- Уход со страницы, в фон и аудиопрерывание отменяют диктовку. Телефонный
  аудиосеанс имеет приоритет. Сохраняется/восстанавливается прежняя категория
  AVAudioSession, если чат действительно её занимал.
- Временный аудиофайл удаляется после чтения, отмены или ошибки. При сетевой
  ошибке аудио остаётся только в оперативной памяти для явного повтора.
  После закрытия процесса нужно записать заново; автоматического STT нет.
- Локальная тишина проверяется по уровню; пустая расшифровка обрабатывается
  отдельно. Это не новый семантический VAD и не доказательство качества STT.
- Текст и уже загруженные вложения черновика сохраняются по пользователю,
  origin сервера и чату, восстанавливаются после открытия приложения.
  Незавершённая загрузка сырого файла не сохраняется автоматически.
- Меню `+`: **Files работает прежним документ-пикером** с прежними проверками
  форматов, размера, владельца и upload requestId. **Camera/Photos явно
  неактивны**, есть объяснение. Поэтому новые разрешения камеры/фототеки не
  запрашиваются. PNG/JPEG можно выбрать через Files.
- Плотнее интервалы сообщений и компактнее ввод. Светлая/тёмная палитры
  динамические. Нижняя навигация не изменена. Новые строки — во всех пяти
  текущих локализациях EN/RU/ES/KK/UK, без переключателя языка внутри чата.

## Проверка на Mac до приёмки

1. Перенести изменения в отдельную **Dev**-сборку существующего приложения.
   Не менять endpoint установленной боевой сборки. Патч в ZIP применять
   только если эти изменения ещё не перенесены; собственные правки сохранить.
2. Из корня репозитория: `bash ios/scripts/validate-native.sh`.
   XcodeGen подхватывает новые `.swift`, затем полный XCTest и
   `verify-xcresult.py`; Archive/TestFlight/Publish не запускать.
3. Проверить реальные состояния UIKit на компактном/большом iPhone:
   клавиатура, табы, прокрутка, EN/ES/RU (также KK/UK), тёмная тема,
   Dynamic Type, VoiceOver и подписанная недоступность Orb.
4. Сначала тестировать отмену/ошибки со стабами. Настоящее распознавание
   платное; ручной STT только при разрешённой Dev-проверке владельцем.
5. Контрольные сценарии: текст+выделение+вложение → диктовка → правка;
   cancel при записи/STT; отказ разрешения; тишина; сеть/retry; смена чата;
   уход в фон; перезапуск; двойной стоп/отправка; телефонное аудиопрерывание.
   Ожидание — 0 автоотправок, дублей, применений результата к другому
   пользователю/чату, потерь исходного черновика и ложных запусков Orb.

## Крупные экраны

`generated-artifacts/chat-dictation-dev/` содержит отдельные концепты:
обычный ввод, запись, распознавание, редактирование, тёмная тема, вложения.
Это **не скриншоты UIKit runtime** и не доказательство готовности сборки.
Для принятия работающей версии нужен результат Mac-проверки выше.
