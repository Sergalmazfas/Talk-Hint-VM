# Проверка Chat 1A на Mac

Нужен существующий репозиторий TalkHint, Xcode, xcodegen и Simulator.
Archive, TestFlight, Publish и звонки не входят в эту проверку.

1. Проверить чистоту рабочей копии. Сохранить собственные правки до переноса.
2. Перенести изменения из приложенного changes.patch либо получить
   согласованную ветку репозитория. Не накладывать патч повторно поверх
   уже содержащей его версии.
3. Из корня проекта запустить существующий harness:

```sh
git status --short
bash ios/scripts/validate-native.sh
```

Harness создаёт отдельный Simulator, собирает validation-схему, выполняет
тесты и проверяет xcresult. Он работает без live backend и телефонных действий.
Должны выполняться новые `ChatAPITests`, `ChatOutboxTests`, а также обновлённый
`CopilotFreezeNavigationTests`; новые файлы подхватывает существующий XcodeGen.
Количество native-тестов не объявляется заранее: сверить полный результат
и отсутствие пропущенных тестовых файлов.

4. На Simulator проверить клавиатуру/прокрутку/боковое меню, светлую тему,
   Dynamic Type и русский/английский язык. Ещё три перевода также включены.
5. Для функциональной проверки использовать **Dev**, не production:
   - два разных пользователя не видят разговоры и файлы друг друга;
   - новый чат, сообщение, закрытие/открытие приложения, выход/вход;
   - повтор при потере сети не создаёт второй ответ;
   - оборванный ответ остаётся явно незавершённым без фонового повтора;
   - TXT/PNG/PDF: загрузка, ошибка, повтор, имя после перезапуска, скачивание;
   - голос → расшифровка → редактирование → отдельная отправка;
   - микрофон чата не забирает телефонное аудио.

Текстовые AI/STT-запросы — реальные внешние операции при ручной работе.
Автоматический harness не должен их выполнять. Живые звонки для приёмки
основы чата не нужны.

Не менять адрес боевого backend установленного приложения ради этой проверки:
использовать отдельно настроенную Dev-сборку/схему и явно сверить endpoint.
Если Xcode обнаружит проблему, прислать diff и xcresult/сводку, не запускать
Archive или TestFlight для обхода проверки.
