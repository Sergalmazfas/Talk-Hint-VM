# Уроки ручной работы — proposed

Фактический автор: Replit. Подготовлено для предложения Ниной и приёмки
владельцем. Не записано в production-книжки/MCP; агенты не запускались.

## Фома / Тихон — отменённая диктовка не должна оживать

**Что было:** поздняя расшифровка могла заменить набранный текст после ухода
со страницы; запись отличалась от голосового разговора только иконкой.
**Что узнали:** отмена HTTP недостаточна — результат надо сверять с владельцем,
чатом, версией черновика и попыткой; распознавание само ничего не отправляет.
**Как действовать:** проверять отмену и поздний ответ раздельно, сохранять
черновик и вложения; недоступный будущий голосовой режим не запускает аудио.
Статические проверки не заменяют XCTest и проверку микрофона на iPhone.

**Ожидаемый результат:** 0 неявных отправок, 0 дублей, 0 запоздалых замен
черновика другого чата, 0 запусков недоступного Voice Orb.

## Мария — границы этапа

**Что было:** макеты показывают сразу чат, память, поручения, почту и календарь.
**Что узнали:** наличие карточки/пункта меню не доказывает готовность операции;
постоянная переписка сама по себе ещё не подтверждаемая память.
**Как действовать:** принимать каждый этап отдельно; в 1A будущие разделы
обозначать недоступными. Не считать визуальное согласование доказательством
работы API, iPhone и полномочий на внешние действия.

**Ожидаемый результат:** 0 заявленных выполненными недоступных операций;
0 автоматических переходов из 1A к следующему этапу.

## Тихон — восстановление без платного повтора

**Что было:** клиент может потерять ответ HTTP или сервер — процесс генерации.
**Что узнали:** повтор по новому ID создаёт новое платное действие; отсутствие
ответа не означает отсутствие уже принятой работы.
**Как действовать:** проверять сохранённый requestId, состояние и lease;
читать существующий результат, после прерывания не повторять автоматически.
Принимать это только по проверке параллельных дубликатов и перезапуска.

**Ожидаемый результат:** 1 генерация на один принятый clientRequestId,
0 автоматических генераций после interrupted/unknown.
