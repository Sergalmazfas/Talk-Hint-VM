Собрать **всё приложение с Chat**, подключённое **сразу к рабочему серверу**,
а не ещё одну отдельную Dev-демонстрацию. Сборка и установка — через Claude на Mac.
Изменять утверждённый дизайн не нужно.

Проверенный адрес опубликованного сервера: **https://talkhint.app**.
Этот адрес подтверждён метаданными публикации Replit, не выведен из имени проекта.

## Что изменено в новой дельте

1. Обычная схема приложения теперь использует Chat вместо Copilot, как и AppDev.
   Chat открывает утверждённый подключённый экран полноэкранно. Назад возвращает
   к прежней вкладке; переписка и черновик сохраняются существующим механизмом.
2. Парольный вход и Google-вход считают сессию сохранённой только после успешной
   записи **и чтения** Keychain. Ошибка не открывает вкладки, не хранит токен
   в UserDefaults, а показывает локализованное сообщение.
3. При исчезновении сессии вход в Chat показывает авторизацию, а не
   `preconditionFailure`. Существующие настройки и ключи не переименованы.
4. Dev-схемы имеют явно собранный Dev-адрес в Info.plist для запуска с иконки.
   Недопустимый адрес по-прежнему запрещён; fallback на production в Dev не добавлен.
5. Убрано создание MainActor-контроллера из аргумента по умолчанию.
   QuickLook dismissal передаёт очистку файла на MainActor и связывает файл
   с конкретным preview, чтобы поздний callback не удалил новый файл.
6. Добавлены шесть XCTest для сбоев secure storage и пять исходных контрактов.

## Gate на Mac — до установки

1. Прочти штатный `ios/scripts/validate-native.sh` и выполни полный действующий
   gate, не только тесты чата. Сохрани xcresult и вывод `verify-xcresult.py`.
   Предыдущая база — 261 passed / 0 failed / 0 skipped; шесть новых тестов
   SessionCredentials должны реально выполняться. Не заменять Keychain моком
   в существующем интеграционном тесте secure storage.
2. Собери также **обычную схему TalkHint**, не ограничиваясь NativeValidation/AppDev.
   Для Simulator нужна корректная подпись и entitlement application-identifier:
   unsigned-сборка ранее давала Keychain -34018. Не обходить ошибку plaintext-хранилищем.
3. Проверь актуальный набор предупреждений и 13 прежних `Unbalanced calls`.
   Два предупреждения чата исправлены здесь, но их исчезновение требует компиляции.
   Остальные прежние предупреждения не объявлены исправленными:
   CallManager/CallKit/Twilio actor boundaries, Copilot Sendable/audio pointers,
   Objective-C capture, deprecated API, предупреждения стороннего TwilioVoice.
4. Исправляй воспроизводимые first-party ошибки отдельными небольшими коммитами
   с тестами. Не скрывать предупреждения массовыми `@preconcurrency`,
   `@unchecked Sendable` или отключением diagnostics. Не редактировать vendor-код
   ради косметики и не включать замороженный Copilot. При риске изменения реального
   аудио/телефонии — сообщить конкретный риск, не маскировать его зелёной сборкой.
5. Проверить Chat → назад → Chat, черновик, перезапуск, клавиатуру маленького экрана,
   открытие/закрытие файла, диктовку через существующие offline-фикстуры, локализации.
   Проверить возврат из имитированного звонка; реальный звонок не делать.

## Настоящий iPhone

После зелёного gate и успешной публикации серверных таблиц чата:

- Схема **TalkHint**, конфигурация обычная Debug для первого запуска на устройстве,
  bundle **app.talkhint**, URL scheme **talkhint**.
- **НЕ TalkHintAppDev / TalkHintChatLiveDev**, не bundle app.talkhint.chatdev.
- В конфигурации установленного приложения не должно быть
  TALKHINT_NATIVE_VALIDATION / TALKHINT_CHAT_PREVIEW / TALKHINT_CHAT_LIVE_DEV /
  TALKHINT_APP_DEV. Иначе можно получить неправильный сервер или отключённый
  автоматический запуск телефонных сервисов.
- Эффективный backend: https://talkhint.app. Проверить как при Run, так и после
  остановки Xcode и запуска с иконки. Не добавлять Dev-адрес в обычную сборку.
- Подключи физический iPhone, проверь pairing/Developer Mode и существующую
  автоматическую подпись. Не менять Team, сертификаты и APNs вручную.
- Это обновление установленного TalkHint с тем же bundle ID. **Не удалять приложение**:
  сохраняем его Keychain, настройки, локальные данные и серверную историю.
  Dev-переписки другой базы автоматически в production не копировать.
- Вход через привычный Google/Replit выполняет владелец. Пароль/токен в отчёте не нужен.
  После входа проверь доступ к истории, отсутствие падения и повторный запуск с иконки.
- Первое настоящее сообщение AI и первый звонок отправит/выполнит владелец.
  Самостоятельно не отправлять сообщения модели, не запускать STT, звонки или репетиции.

Никаких новых лимитов живых звонков; 180 секунд относится только к стенду.
Не менять голос, модель, Retell, серверные настройки, планы и текущую телефонию.
При нехватке диска не удалять Корзину, симуляторы и DerivedData без отдельного разрешения.

## Что вернуть Replit

Точный новый Mac HEAD и список собственных исправлений; полный gate/xcresult;
build основной схемы и перечень оставшихся предупреждений с оценкой риска;
подтверждение bundle/scheme/backend/signing без секретов; результат запуска
с иконки на физическом iPhone; крупные скриншоты вкладок/чата/возврата;
патч только новых Mac-исправлений. Нельзя писать «установлено», если проверен
лишь Simulator. Archive/TestFlight/App Store не выполнять.

Публикацию сервера делает владелец в Replit. Xcode-установка обновляет iPhone
отдельно: Publish сайта сам по себе не устанавливает новый нативный экран.
