# TalkHint Chat — помощник по действиям: Dev-пакет

Статус: техническая реализация в Dev, независимая приёмка Клавдием и
нативная сборка на Mac ещё не выполнены. Это НЕ сообщение о Publish.
База: `cac6bbf` (предыдущая отметка Publish; код FleetPride IVR — `9397cac`).

## Контроль жизненного цикла и безопасности

- Текстовая модель умеет только предложить план и читать места. Ни один tool
  не звонит, не покупает, не отправляет SMS/почту и не изменяет календарь.
- Подтверждение владельца подписано прежним HMAC: владелец, вся инструкция,
  время и необязательный источник карточки. Старые токены остаются совместимыми.
  Длинный токен сохраняет поле instruction, используемое установленным iOS
  для проверки свежести. Никаких capabilities в истории сообщений.
- Привязка задачи проходит до dial; расхождение источника останавливает вызов.
  Повтор чтения/события не создаёт модель, звонок или вторую доставку.
- Пользовательский результат и независимая проверка команды — разные события.
  «Не подтверждено» не превращается в успех.
- История, черновики, контекст попытки и idempotency сохраняются. Повтор отправки
  использует тот же snapshot времени/места, а не новую геолокацию.
- Геоданные — пользовательские данные в его сообщениях, не подтверждённая
  долговременная карточка. Историческое местоположение подписано как историческое.
- Новых таблиц, миграций, фоновых агентов и постоянного CRM нет.
- Все model usage по tool rounds сохраняются, а не только последний запрос.

## Google Maps: конфигурация и граница проверки

Google Maps выбран владельцем. Поддерживается серверный ключ
`GOOGLE_MAPS_API_KEY` либо OAuth service account из
`GOOGLE_SERVICE_ACCOUNT_JSON` (Google auth library, cloud-platform scope).
Ключи, JSON и access tokens не выводятся, не отправляются модели/телефону.
`GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET` для этого server-to-server пути
не требуются; вход Google, Gmail и Calendar не изменяются.

Наличие Secret = только конфигурация, не проверенные IAM/API/billing.
Реальные запросы Places/Routes и платные model probes не делались.
В Google-проекте должны быть разрешены Places API (New), Routes API,
оплата и необходимые права service account. 403/ошибки авторизации
показываются явно, без повторов и без фиктивных результатов.

В текущем пакете отдельный фильтр доказанного highway-only доступа и точный
автомобильный detour НЕ реализованы: геометрическая близость не доказывает
съезд с трассы. Такой вариант нельзя выдавать за подтверждённое соответствие.
Это остаётся предметной проверкой перед договорённостью.

## Offline replay

Сценарии: ручка опор Fontaine / I-44 E / только у трассы;
EarthLite Harmony DX / Missouri → Michigan / бюджет $550.

Проверены контракты: phone context → ограниченный read-only поиск →
источники/unknown price → предложение плана → отдельное owner confirmation.
Map/model transport используют явно синтетические fixtures.
Это НЕ два настоящих разговора AI и НЕ доказательство, что реальная модель
уложилась в три вопроса или нашла товар за нужную цену.

## Проверки и передача

- Результаты полного Vitest — в `verification/` ZIP.
- Dev public landing после рестарта открывается; это НЕ визуальная проверка
  авторизованного нативного чата. После серверного пакета нужна новая iOS-сборка.
- Отдельные PostgreSQL проверки выполнены в Dev: 10 passed, без оплачиваемых
  операций; тестовые строки удалены штатным cleanup.
- TypeScript и проверки plist/пяти локализаций — отдельные логи.
- В Linux нет macOS/Xcode/iPhone Simulator: нативные тесты НЕ выполнены.
  Исходники и три новых XCTest передаются Claude на Mac.
- Полный список native файлов/сборки: `docs/claude-mac-chat-actions-handoff.md`.
- Уроки — proposed в пакете, не записаны в production-книжки.

## Откат

Не удалять историю/планы/задачи и не чистить базу. Отменять именно код пакета
через отдельный проверяемый revert на резервную базу; новые сообщения остаются
в существующей схеме. Старый native клиент не умеет новые действия, но
обычную историю продолжает читать. Старый серверный лимит 2000 после отката
снова отклонит длинные новые поручения — это известное последствие отката.
Publish выполняет только владелец после независимой проверки; при DROP/DELETE
на экране схемы — STOP. Обновление сервера не устанавливает iOS-сборку.
