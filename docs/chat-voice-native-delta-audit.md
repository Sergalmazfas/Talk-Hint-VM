Это не синхронизация всего Dev-репозитория и не ZIP поверх Mac.

| Слой | Что перенесено |

## Зачем нужны изменения действий чата

Mac ещё не содержал 38 ранее выявленных отличий действий чата от Replit.
Нельзя добавить только экран голоса: его отправка использует уже подготовленные
контекст, outbox и модели плана. Взяты следующие существующие зависимости:

| Пути / группа | Назначение и ограничения |
|---|---|
| `ChatAPI.swift`, `ChatOutbox.swift`, `ChatPhoneContext.swift` | Серверный контракт планов, устойчивые request ID, контекст времени/локации только по существующей логике |
| `ChatViewController.swift` | Карточки действий, подтверждение, сохранение черновика; тот же разговор для голоса |
| `APIClient.swift` | Явные ошибки изменившегося плана и поток PCM; Google-вход сохранён |
| `SceneDelegate.swift` | Те же пять вкладок и вход в удерживаемый полноэкранный Chat; строгая проверка сессии не ослаблена |
| `CallManager.swift`, `CopilotStream.swift`, `HomeViewController.swift` | Уже существующая заморозка Copilot, без автоматического перехода в обычный звонок; входящий режим не зависит от номера вкладки |
| `SecretaryAlertManager.swift`, `SecretaryViewController.swift` | Навигация по идентификатору вкладки; читаемый текст плана вместо технической инструкции на экране проверки |
| `SecretaryLiveCallViewController.swift` и соответствующий тест | Существующее Dev-уточнение: потеря read-only аудио не означает провал самого звонка; оранжевое предупреждение вместо красного |
| `Info.plist`, пять `InfoPlist.strings` | Разрешение локации для существующего контекста чата; не автоматический доступ |
| Пять `Localizable.strings` | Ключи действий/голоса; ни один старый Mac-ключ не удалён |
| Тесты моделей/контекста/навигации | Проверка изменённого контракта без реальных звонков |
| `NATIVE_PLAN_HANDOFF.md` | Описание существующего Dev-пути действий, не новая возможность Кати |

Это изменения нативного клиента, а не перенос промптов/движка Кати или настроек
Retell. Выполнение настоящего звонка остаётся внешним действием и в проверках
не допускается.

## Голосовой слой

- Новые `ChatVoiceCapture`, `ChatVoiceSessionState`, `ChatVoiceSpeechState`,
  `ChatVoiceViewController`; `ChatVoiceOrbView` и vendored Orb с MIT-авторством.
- iOS 17+ — Orb; iOS 15–16 — отдельный пульсирующий круг. Deployment target
  и SPM-зависимости не менялись.
- Dev-only, доступ проверяет backend; на телефоне нет ключа ElevenLabs.
  Flash v2.5 / Sarah, тот же серверный мозг, история, инструменты и разговор.
- Отправка голоса проходит через outbox с прежним request ID при повторе.
  Речь идёт потоково по первым законченным фразам; при перебивании сначала
  локальный stop, затем отмена серверной генерации.
- Рабочая пауза **1,2 с**. Предложение 0,8 с не включалось.
- Владельческий потолок TTS $5/день и нормализация RU/ES/EN находятся на
  существующем Dev-сервере. Это не общий потолок расходов STT/модели.

### Что сознательно не выдаём за готовое

Голосовое «да» не запускает звонок Кати: реальный audible-readback плана
ещё не подключён к безопасному подтверждению. Путь остаётся закрытым,
действующая карточка — единственный готовый путь подтверждения.
Нативная компиляция, акустика/AEC, физическое перебивание, настоящее бюджетное
письмо и три полных end-to-end замера в Replit не проверены.

## Проверки и откат

Replit выполняет неплатные проверки исходников на **извлечённом конечном дереве**,
а не только в своей рабочей копии. Результаты приводятся в задании Mac после
проверки. Это не доказательство успешной компиляции Swift или работы на iPhone.

Откат: закрыть новый проект/worktree и открыть прежний `iphone-ready` с
`c997a2d`. Старый checkout не изменяется. Не удалять Keychain, историю, приложение,
кэши или симуляторы владельца. Если позднее будет установлен новый Dev binary,
возврат бинарника — отдельная контролируемая владельцем установка прежней сборки.
