# Hint: этап A, QC30

Это описание метода, **не приёмка базовой линии**. Итоговые цифры берутся из
`generated-artifacts/hint-polygon/qc30-report/report.json` и `comparison.csv`
после завершения обеих групп. Неполную таблицу нельзя называть полной базой.

## Границы

- Старый стенд, рабочий Hint, телефония, сотрудники и их работающие модели не менялись.
- Основная группа: 15 записей с сохранённой целью. Одна удержана из-за прежнего
  unknown STT; её не повторяем. Отдельная группа: 21 запись без цели.
- Короткая техническая проверка `b23b1756` — **без сохранённой цели**.
  Её нельзя выдавать за goal-driven базу.
- Все диагностические, невалидные и unknown попытки остаются в одном бюджете $15.
  Оценка по usage и длительности отправленного STT — не счёт провайдера.

## Что изменено в методе

- Неоднозначные измеряемые Guest-реплики исключаются отдельно. Звонок невалиден
  при доле выше 30%; ровно 30% допускается. Отсутствующие хвостовые Guest-сегменты
  учитываются, повторно один сегмент не считается. Owner-окна сохраняются для
  диагностики; порог Guest-QC нельзя называть QC всех реплик обоих участников.
- Неоднозначность не обрывает аудио: следующие реплики продолжают обрабатываться.
  Ошибки API отдельно исключаются из итоговой проверенной таблицы, без изменения
  исходных JSON результатов.
- Каждый канал — исходный 8kHz, разделение PCM16 → μ-law без улучшения звука.
  У каждой записи собственные 1x-часы. Допуск планировщика 300 мс отражён в данных.
- WAV подготавливаются до запуска аудиочасов. Резерв атомарно сохраняется на диск
  до API-запроса; асинхронный fsync не останавливает аудиотаймеры.
- Четыре записи идут параллельно в одном процессе с одним бюджетным журналом.
  Короткие smoke-тесты выбираются первыми; полный следующий пакет планируется
  от длинных записей к коротким, чтобы последние записи не выполнялись по одной.
- Готовый английский фиксируется после разбора содержимого, не по первому HTTP
  байту или JSON-токену и не после задержки записи расходов на диск.
- Цена записи считается только по её собственным запросам, без расходов соседей.
- После основной группы запускается отдельная группа без цели. Повторный запуск
  управляющего скрипта блокируется одноразовым маркером.

## Проверки и ограничения

Выборочный regression-набор: 100 тестов, 8 файлов, 0 падений; общий `tsc --noEmit`
успешен. Это **не полный Vitest всего проекта**. Отдельно реально пройдены короткая
запись и три записи с целью; длительный корпус измеряется отдельно.

Статистика — серверная цепочка. Не измерены отображение карточки на iPhone,
парное соответствие тем же живым звонкам и полная эквивалентность live-контекста.
Нельзя объявлять её доказанной только из-за попадания p50/p95 в диапазон 2–5 секунд.

## Следующие архитектуры

В `experimental/realtime.ts` находится **неподключённый прототип**, а не готовый
adapter Б. Его расчёт цены и извлечение английского слова проверены без платных
запросов. Реально подтверждены каталог модели и конфигурация текстовой Realtime-
сессии без аудио/генерации. Это **не успешный платный audio → hint опыт**.
Ни Б, ни В–Е в этой передаче не заявлены выполненными. Они не переключают продукт
и используют оставшуюся часть того же бюджета, когда действительно запускаются.
