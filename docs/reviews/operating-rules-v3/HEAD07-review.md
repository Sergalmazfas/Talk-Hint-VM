## Расхождения и решения по приложенному v2

| Пункт v2 | Что сделать | Статус |
|---|---|---|
| До трёх повторов на звонок без вопроса | Не вводить новое разрешение; сохранить существующую границу отдельных диагностик | Нужно решение владельца, если хочет расширить |
| Два возврата QA | Упоминаются в памяти как согласованная спецификация, но это не проверка фактического счётчика выполнения | Ранее записанное требование; runtime не проверен |
| 08:00 ежедневно | Оставить час null; утвердить вместе с границами периода | Предложение, не запущенное расписание |
| «Сроков нет» | Нет искусственной отсрочки; внешние сроки и технические пороги остаются | Требует согласования уточнённой формулировки |
| Dev и production не изолированы | Проверять отдельно БД, провайдеров, почту, вебхуки; не утверждать общую топологию без проверки | Не подтверждено этим аудитом |
| «Лучше/отлично» закрывает всё | Сохранять оценку владельца, закрывать после обязательных проверок; не подменять безопасность удобством | Предложение уточнения |
| Оговорки только в полном отчёте | Критические ограничения QA/синтетики/данных видны и в коротком | Предложение уточнения |
| Replit заменяет неподключённые роли | Только временное исполнение по поручению; не подключённые автономные сотрудники | Уточнение границ |
| Запись звонков | Не менять, не включать и не предлагать подключение этой задачей | Граница текущего поручения |
| Ears: четыре дефекта | Исторические сообщения — не новый прогон; не выдавать исправленность стенда за установленный факт | Состояние сейчас не перепроверялось |
| Самоприёмка запрещена | Разделить формального принимающего, текущего исполнителя и независимость проверки | Ранее записанный принцип |

## Решения, необходимые перед единым применением

1. Утвердить кандидат коротких правил v3 и уточнения выше.
2. Утвердить журнал как документ той же модели и предложенные связи/записи;
   фактическую оценку внедрённых изменений оставить «ждёт».
3. Утвердить доработку существующих документов P.OPS, не считать её приёмкой роли.
4. Передать исходник ручного прохода P.OPS v2, если он хранится вне текущего пакета.
   В актуальном manualPass нет исполнителя, даты, вердикта или замечаний.
5. Час отчёта, прочие режимы контроля и расширение повторов можно оставить открытыми:
   правила не запускают эти функции автоматически.

Владельцу не требуется повторно утверждать каждую уже разрешённую внутреннюю
операцию. Но подготовка этого ZIP не является согласием на его применение.
