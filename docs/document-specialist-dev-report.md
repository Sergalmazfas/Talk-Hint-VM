### Пользовательский путь

`Чат → + → Файлы → приложить фото/PDF → + → Распознать вложенные документы`.
В чат приходит отдельная карточка каждого распознанного документа. До Save
постоянная память не меняется. Оригинал можно просмотреть в меню «Документы».
Если тип не определён — нажать документ и выбрать тип; выбор также доступен
через текстовый чат с явным указанием типа.

Существующий рендер памяти уже умеет одну Save/Cancel. iOS-дельта добавляет
до 10 вложений, подсветку «проверь», список документов, выбор типа,
скачивание/закрепление/закрытие/скрытие/историю. Ручного редактора значений
в этой дельте нет: сомнительное можно не сохранять и предоставить более
чёткий документ. Поля null не заменяются догадками.

Агата читает собственные сохранённые документы через те же средства истории.
Платные операции распознавания не выдаются её live-meter, чтобы не обойти
лимит голосового сеанса: запуск — явной кнопкой в чате. Никакого голосового
Save памяти нет.

## Хранение

| Действие | Поведение |
|---|---|
| Извлечённые поля/метки | Хранятся постоянно; не удаляются вместе с оригиналом. |
| Закрыть | Незакреплённый оригинал удаляется через календарный год после закрытия. |
| Закрепить | Исключает годовую очистку, пока удаление ещё не началось. |
| Забыть | Скрывается сразу, поиск/контекст исключают сведения. Оригинал удаляется через 30 дней даже при закреплении. |
| Восстановить | Только до начала физического удаления и до 30-дневного срока. Это не восстановление уже удалённых байтов. |
| Сбой удаления | Необратимое намерение фиксируется ДО внешней операции; нельзя ложно пообещать pin/restore. Следующий часовой проход повторяет только удаление, не AI. |

Очистка работает при работающем сервере, раз в час, порциями по 25. Это срок
постановки на удаление с ближайшим проходом, не обещание удаления ровно до секунды.
Скачанные ранее пользователем копии не отзываются.

## Цена и тесты

- Платных модельных запросов, звонков и писем в этой задаче **0**; фактическая
  внешняя стоимость тестов **$0**. На настоящих документах точность ещё не измерена.
- Для реальных запусков `document_attempts` хранит модель, стадию, requestId,
  status, provider usage и зафиксированную оценку cost_micro. При неизвестном
  расходе — неизвестно, не выдуманный ноль; автоматического повторного AI нет.
- Внутренний тариф резерва: вход $2.50/млн, выход $10/млн; это **не счёт провайдера**.
  Пример двух проходов, всего 4000 входных + 800 выходных токенов: **$0.018**.
  8000 + 1500: **$0.035**. Фото/страницы и число полей меняют расход.
- Mini не подключалась и не назначалась. Её можно сравнить только для
  классификации после отдельного решения, проверки доступности/vision/тарифа
  и качества на разрешённой выборке.
- Предохранители: один документ в обработке на пользователя, два одновременно
  на сервере, до 40 попыток стадий в час на пользователя. Неизвестный расход
  не запускает автоматический повтор.
- Проверены каталог, четыре схемы, реальные sharp/Poppler на синтетике,
  ошибки/пакеты/дубли/изоляция пользователей, Save/Cancel/stale/expired,
  новые карточки без AI, история/откат, pin/год/30 дней и сбой удаления.
- Заключительный прогон: **641 проверка, 53 файла, все прошли**. Включены
  Dev PostgreSQL, чат, память, документы, защита старых путей вложений,
  повтор очистки при неизвестном результате и новая карточка без AI.
- Дополнительно **31/31** связанная проверка полноты схемы и отслеживания
  ошибок сохранения. Обновлены устаревшие фикстуры памяти; новые документные
  таблицы включены в штатную проверку схемы. PostgreSQL-коды ошибок по-прежнему
  проверяются, проверки не ослаблялись. Итого 672 успешные проверки.
- Старый полный workflow содержал 7 ошибок этих фикстур; они воспроизведены
  и исправлены указанным отдельным прогоном. Полный многотысячный набор после
  этого не перезапускался: его старый красный статус не является новым прогоном.
- TypeScript проверен. XCTest, Swift-компиляция и установка на iPhone в Replit
  **не выполнялись**: требуется Mac по единому заданию. Скриншот веб-входа
  не подтверждает работу нативного экрана документов.

## SQL перед Publish

Только `CREATE TABLE/INDEX IF NOT EXISTS` и `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`.
Полный файл: `docs/document-specialist-schema.sql`.

| Новое | Для чего |
|---|---|
| document_types | Версионированный каталог |
| user_documents | Черновое/сохранённое извлечение, статус, даты хранения |
| document_files | Закрытая связь с исходными вложениями |
| document_attempts | Этапы, usage и стоимость |
| document_versions | Подтверждённая история |
| ADD saved_result | Разделить неподтверждённый результат и сохранённые факты |
| ADD file_deletion_started_at | Не обещать сохранность оригинала после начала удаления |

Dev-схема применена. Production SQL напрямую не выполнялся. После слияния
Dev-подготовка идемпотентна в `scripts/post-merge.sh`; в production этот скрипт
подготовки запрещён. Схема production — через проверку Publish владельцем.

## Риски, откат и порядок

1. Это Dev-проверка, не доказанная точность OCR четырёх реальных документов.
   Синтетика и mock API не доказывают доступность модели в production.
2. sharp/Poppler/prlimit и App Storage должны быть доступны опубликованному
   серверу. Зависимости добавлены; никакие ключи/агенты Retell не менялись.
3. Сначала Publish сервера владельцем и проверка `/api/build`/новых таблиц.
   Потом одна обычная сборка iOS по постоянной ветке; не публиковать сервер
   из native-ветки и не переносить в неё всю серверную ветку.
4. Откат к предыдущему серверному checkpoint **без удаления новых таблиц/полей**.
   Данные и история остаются. Старые приложения/обычный чат сохраняют свой
   контракт; новая кнопка требует нового сервера.
5. Уже физически удалённые оригиналы откатом кода не восстановить.
   «Отключить запись памяти» общим флагом отключает и обычную память — это не
   отдельный переключатель Документоведа. Не менять его молча.
6. Катя, Hint-звонки, Retell-агенты, телефонные маршруты, существующие модели
   и минимум iOS 15 не менялись. Publish не выполнялся.
