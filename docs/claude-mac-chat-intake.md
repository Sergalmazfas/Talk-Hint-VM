## Сервер первым

Сначала владелец делает Publish сервера из основного TalkHint Replit; Replit
подтверждает production commit через `/api/build`. До этого допустимы целевые
тесты iOS, но **сборку/установку для проверки новой функции не начинать**.
Сервер из native-ветки НЕ публиковать. Сервер добавляет общий стандарт опроса и
мягкие `action.warnings`; старые карточки без этого поля остаются совместимыми.

## Изменения

1. `ChatAPI.swift`: дополнительное необязательное поле `warnings` у карточки.
2. `ChatViewController.swift`: текст «Не хватает: …» перед содержимым карточки.
   Это **не блокировка**, не новая кнопка и не изменение подтверждения.
3. `ChatPlanPresentation.swift`: подписи по языку приложения; показ читаемого
   структурированного плана вместо JSON в существующем экране проверки.
4. `HomeViewController.swift`: только отображение instruction. Оригинал
   `draft.instruction`, HMAC, planHash, номер и запуск НЕ изменяются.
5. Один новый ключ во всех пяти локализациях, пять новых целевых XCTest.

Текст плана создаёт сервер на языке интерфейса. Язык звонка — отдельное поле.
Старый или внешний английский текст не переводить локально догадками;
только подписи локализованы. Старые свободные инструкции показывать без изменений.

## Проверка и одна сборка

- Replit: TypeScript, серверные тесты, локализационные ключи; Xcode недоступен,
  XCTest/установка на iPhone ещё НЕ выполнены.
- Запустить только `ChatPlanPresentationTests`, `ChatCallPlanModelTests`,
  `ChatAPITests`, `SecretaryConfirmationRecoveryTests`, `ChatVoiceSessionTests`.
  Никаких реальных сетевых/голосовых/платных операций.
- Новые Swift-файлы включаются через существующий `project.yml`; при необходимости
  штатно регенерировать проект, без обновления зависимостей и без clean.
- После подтверждения серверного Publish — **одна** incremental обычная сборка
  `TalkHint` / `Debug`, bundle `app.talkhint`, сервер `https://talkhint.app`.
  Не AppDev/ChatLiveDev, не новая URL-схема.
- Установить поверх существующего приложения без удаления данных. Не Archive,
  TestFlight, Publish, не звонить, не отправлять задания/письма от имени владельца.
- Упавшие связанные тесты, новая ошибка сборки/авторизации — остановка. Только
  узкое исправление отдельным коммитом; сообщить commit для возврата Replit.

## Владельцу на телефоне

1. В русском интерфейсе подготовить справку об аренде: дата въезда и срок
   аренды спрашиваются отдельно, уже заданный английский повторно не спрашивается.
2. Открыть карточку с пропусками: видна мягкая строка «Не хватает»; карточка
   открывается как раньше, без автоматического запуска звонка.
3. Перейти в проверку поручения: читаемые русские подписи вместо JSON;
   выйти без запуска, вернуться в чат — история и черновик остаются.
